# 上线前基础数据维护指导

[下载Excel填写表](../deliverables/prelaunch-data-maintenance-1.2.1.xlsx)。适用当前1.2.1后台和小程序，包含11个可见工作表；7个基础填写表各留100行，示例另放一页。文件不含宏、真实密码或业务数据库连接。

## 管理员按什么顺序维护

1. **人员与岗位**：编辑原管理员，核对本人手机号和启用状态；添加实际司机、装菜人员、出库员及需要的会计。账号和员工本人手机号须唯一。管理员/会计独立密码只在后台设置；普通员工通过微信本人确认。
2. **棚户、包装、蔬菜、客户**：分别在“基础档案”建档并启用。包装名称/单位必填、数量整数；蔬菜只允许箱或公斤，公斤最多3位小数。已使用品类不能随意更改库存单位。
3. **仓库盘点**：确定实际切账日期，盘点实物并查询已有系统仓库余额。空库且确认从未入账才做首次期初；已有业务库先核对历史，必要时用有原因的库存调整处理差额。不重复录入实盘总数。
4. **未结棚户任务**：如果还有在外包装或装菜尚未运回的蔬菜，单独核对，不记作仓库期初。先决定结清、沿用已有批次或制定切换方案，不能直接用盘点表重放历史交易。
5. **会计权限、本人微信和上线核对**：会计默认查/导出，额外权限由管理员配置；实际员工本人微信核对姓名并绑定。最后核对库存、业务流程、动态提醒、操作审计及维护人员负责的服务条件。

## Excel各工作表

| 工作表 | 用途 |
|---|---|
| 00维护指导 | 维护顺序、关键规则和后台入口 |
| 01维护清单 | 14项准备事项、负责人、计划日期与完成状态 |
| 02人员账号 | 本人资料、5个岗位是/否、密码设置状态、微信绑定核对与表内格式检查 |
| 03棚户档案 | 棚户名称、可选联系人/电话、启用 |
| 04包装档案 | 包装名称、计数单位、规格、启用 |
| 05蔬菜档案 | 蔬菜名称、箱/公斤、规格、启用 |
| 06客户档案 | 实际收货客户、可选联系方式、启用 |
| 07期初盘点 | 实盘、已有系统余额、自动差额、处理方式、复核人与入账单号 |
| 08未结任务 | 在外包装/未入仓菜、原任务与切换方案 |
| 09上线核对 | 12项实际验收事项、负责人和问题安排 |
| 10填写示例 | 示例和字段口径，不是待上线业务数据 |

蓝字区域供填写；浅黄色为自动核对公式。手机号按文本保存，下拉选项与名称/数量校验辅助填写。字段旁“*”为完成该行所需内容。后台已有账号与本表之间仍须人工核对；Excel不会读取线上数据。

**当前系统不支持该表批量导入。**填写后按各页列出的后台入口人工维护。期初和调整必须核对后通过单据正式入账；本表中的差额不自动改库存。零实盘可记为0，但后台不创建0数量入库单；负差额经核实做出向调整时填写正数绝对值。

**自动检查只属于本表。**唯一性检查覆盖已提供的100行，不能代替服务端校验、本人身份核实、库存复核或密码设置。打开Excel后会自动计算公式。

生成脚本为`scripts/generate-maintenance-workbook.py`，使用XlsxWriter3.2.9。执行`python3 scripts/generate-maintenance-workbook.py`可重新生成空白表。生成文件已经用openpyxl核对页签、命名下拉、公式、格式与文件结构；未声称操作过用户生产数据库或在Microsoft Excel客户端实测计算。
