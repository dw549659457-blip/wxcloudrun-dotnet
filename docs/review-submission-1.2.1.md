# 小程序审核填写说明（对应工程1.2.1）

## 可直接粘贴的版本描述

用于棚户蔬菜收发货与包装流转记账。支持本人微信身份核实、按岗位操作、包装派发、装菜登记、分次回收与结清、蔬菜出库、库存和历史记录查询。管理员可查看库存变动、未读动态，并在主动订阅后接收库存更新提醒。优化大字界面、数量核对和异常提示。

共116个字符，低于截图所示的200字符上限。适用于描述当前功能，不包含“无限实时推送”等一次性订阅无法保证的表述。

## 版本核对

截图显示待提交的开发版为1.0.0，而当前交付工程版本为1.2.1。请核对是否已上传最新工程，可在小程序“我的身份”底部查看内置版本。上传时填写的版本号与代码内置版本可能不同，不能仅凭截图判定代码新旧；确认提交的是自己验收过的包。

## 图片与视频材料

建议上传体验版实拍：本人身份确认、司机工作台、装菜登记、回收确认、出库登记及管理员动态。使用本手册31张图作为操作参考；手册后台为隔离演示环境截图，小程序为浏览器页面布局示意，不要将其称为微信真机实拍。实际截图和录屏使用演示数据。

## 测试使用说明

实际小程序需微信身份确认并匹配后台登记，截图中“无需登录账号即可使用”不表示当前应用真的没有登录或身份限制。请按审核表单要求如实说明登录方式，并提前准备审核人员可访问的测试用户/协助开通安排，不能只提供网页admin账号密码代替小程序登录。普通员工不输入后台密码，也没有正式开发账号入口。

可在适用的审核说明或测试说明位置填写下段，并补充您实际准备好的审核联系人和测试访问方式：

> 本小程序用于内部蔬菜收发货及包装流转记账。员工由管理员预先登记姓名、本人手机号和岗位，首次使用本人微信核实身份后进入对应工作台。未匹配时可在小程序申请管理员协助，经管理员核实批准后，员工仍需本人确认。司机操作派发与回收，装菜人员登记消耗和产出，出库员登记出库，管理员查询库存动态。微信库存提醒需用户主动订阅，不订阅仍可查看小程序内动态。

现有功能为内部库存记账，未提供网上下单或支付流程；截图中的可选订单中心path没有对应页面，不填写不存在的订单路径。

完整角色步骤见 [图文使用手册](user-manual-1.2.1.md)。
