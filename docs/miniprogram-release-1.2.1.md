1. 已执行006的业务库无需再升级，本次模板配置未新增数据库迁移。尚未升级的已有业务库，在数据库工具执行包内 **数据库升级006.sql**，默认库 `vegetable_prod`。该脚本保留账号、密码、库存、单据、已读状态及订阅记录，重复执行会跳过已完成升级。它要求先有001—005；如果缺005，先执行包内 **数据库升级005.sql**。执行工具须支持DELIMITER。已有业务库不要再次执行首次初始化SQL。
2. Git代码已更新后台功能，按现有云托管流水线部署新版本。先部署代码、尚未升级库时，原记账功能继续可用；管理员动态会提示 `NOTIFICATIONS_NOT_READY`。006成功登记后开始记录新入账，之前的历史单据仍在原报表中，不补发旧通知。
3. 在网页后台“员工账号”中编辑原管理员账号，填写管理员本人唯一手机号，保留ADMIN角色与原密码。手机号变化会撤销旧会话，重新登录即可。管理员在小程序用本人微信核实手机号、核对姓名并确认绑定；已绑定本人微信则直接进入。

## 小程序内动态

- 管理员身份进入专用工作台，页面显示时约每5秒查询一次，离开页面停止刷新。多角色管理员可在“我的身份”切换岗位；会计仍使用网页后台。
- 展示仓库蔬菜和包装库存，各品类保留原单位；查询全部库存支持分页。动态列表有个人未读数、全部已读、历史分页及详情。
- 装菜登记显示在外包装消耗和“装菜产出（未入库）”；回收入库显示实收增加仓库库存；正常/手工发货出库显示仓库减少。包装派发、库存调整、冲销也会记录。
- 只有正式入账成功和正式冲销产生动态；草稿、失败事务和重复幂等提交不新增动态。详情为入账当时的快照，当前余额以“查看当前库存”为准。
- 管理员小程序查询、已读和订阅操作均进入后台操作审计；非管理员不能查询这些动态或调用订阅接口。

## 配置微信服务通知

已按用户提供的小程序模板 **74963「库存更新提醒」** 设置后台默认值，模板场景为收发货：操作人thing8、更新时间time3、温馨提示thing4。默认温馨提示显示首个品类的库存方向、变动数量与单位，如“仓库-3箱 白菜”；装菜产出显示“产出+12箱 白菜”，不误报已入库。完整项目和明细通过消息点击进入小程序查看。

部署此版本后台后即可读取默认模板，无需修改小程序运行配置。如果云托管中已保存旧的空值或其他模板值，请删除以下两个环境变量以使用代码默认值，或按表填写。环境变量优先于默认值；只修改电脑上的.env示例不会修改云服务设置。AppSecret沿用现有服务配置。

| 环境变量 | 值 |
|---|---|
| `WECHAT_NOTIFICATION_TEMPLATE_ID` | `qYyaJOr5BwwRMldhCHEBqhefy7wIvcsNsibhxWA1vrw` |
| `WECHAT_NOTIFICATION_FIELDS` | `{"thing8":"actor","time3":"time","thing4":"summary"}` |
| `WECHAT_NOTIFICATION_STATE` | 体验版 `trial`，正式发布后改为 `formal` |

当前真实模板的字段映射如下，控制台填写时不加外层引号：

```json
{"thing8":"actor","time3":"time","thing4":"summary"}
```

支持内容：`event`事项、`summary`首个品类及变动数量、`actor`操作人、`time`入账时间、`number`单号、`item`首个品类、`quantity`首个品类的绝对数量、`unit`单位、`party`棚户或客户。不混合不同单位合计。支持字段前缀thing、time、character_string、phrase、name、number；time字段必须映射time，number字段只映射quantity。单号适合character_string，其余中文内容优先thing；请以实际模板的内容限制为准。长文本按微信字段长度截取，完整明细可点开小程序查看。

保留现有 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`，保存后部署/重启。管理员点击 **订阅下一次微信提醒** 主动授权，服务只记录该管理员绑定的微信。普通一次性订阅不能无限持续推送；每次接受授权用于下一笔新变动，授权不足时以小程序内动态为准，可再次主动订阅。订阅不是授权历史补发。

管理员可暂停/恢复微信提醒。订阅登记断网时点击“同步订阅结果”，沿用原登记标识，避免重复登记。后台先保存待发送任务，事务提交后调用微信；已明确拒绝、授权不足或配置错误不会影响库存。微信返回忙/令牌错误可有限重试；网络超时与崩溃导致结果不明时保留UNCERTAIN，不盲目重发。管理员工作台显示最近发送状态（微信接收成功不等于用户已读）。多实例共享数据库领取任务；撤权、停用、解绑或暂停在发送前重新校验。
