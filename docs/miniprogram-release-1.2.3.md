# 棚户记账 1.2.3 测试版

本版保留 1.2.2 的后台人员管理和管理员库存动态，并修复三项测试反馈：

- 司机首页的派发入口不再被任务概览查询错误遮住；批次页也可新建派发任务。手机上原有按钮被挤成窄列，本版调整了按钮布局。
- 装菜人员只会看到司机已派发包装、确认记账且未结束的任务。仅建立棚户档案不会生成任务；空列表现在直接说明下一步。
- 后台管理员的员工列表和导出不显示带 ADMIN 角色的账号，包括兼任其他岗位者。最高管理员仍可查看。

小程序整体收紧留白和重复提示，保留主要按钮的大字与触达面积；核对记账时只显示本次摘要和确认按钮，不再重复展示整张输入表单。重要操作用深绿色，损耗与异常用黄色提醒。

## 导入和验收

1. 解压工程包，在微信开发者工具导入 `vegetable-miniprogram` 文件夹，其中应同时有 `project.config.json` 和 `miniprogram`。编译后用真机预览；此包不含生产数据库密码或微信 AppSecret。
2. 用司机岗位查看首页“新建派发任务”，选择测试棚户，填写包装并确认记账。再用装菜岗位查询该棚户任务，核对日期和司机。
3. 用后台管理员打开网页后台“员工账号”及导出，确认不出现 ADMIN 账号；用最高管理员确认仍可查看。此项须先部署本仓库更新后的 C# 后端，单独导入小程序包不会改变后台行为。
4. 在 iPhone、安卓及系统放大字体下检查首页、录入、核对、库存和记录页，确认按钮铺满可用宽度、文字不挤成窄列。浏览器布局检查不能代替微信真机渲染。

已有 005/006 升级的数据库不需新增迁移。没有隔离测试库时，请勿对生产库运行会写入数据的集成测试。验收通过后，上传版本号填写 **1.2.3**；当前测试包尚未替你上传、提审或发布。
