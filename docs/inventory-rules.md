# 库存唯一口径

包装批次：下发 D = 消耗 C + 回收 R + 损耗 L + 在外 O。所有量非负；OPEN 的 L=0，FINAL 的 L=D-C-R、O=0。女工消耗只改变在外账，不再扣仓库；实际回收才增加仓库包装。

仓库包装 = 期初 + 补充 + 回收 + 调整增 - 下发 - 调整减。仓库蔬菜 = 期初 + 外来菜 + 司机实际运回 + 调整增 - NORMAL实际出库 - DIRECT实际出库 - 调整减。女工产出不入仓。

产出/实收差异=累计现场产出-累计实际运回，可为负，不能自动标为运输损耗。不同单位不得相加。

单据草稿不入账；POSTED 才有效；REVERSED 原单效果从业务报表排除，审计流水保留原始与逆转记录。管理员纠错同一事务先冲销再重建，任何步骤失败恢复原单及余额。

月损耗按最终回收业务月统计，分母为这些最终关闭批次的下发量；与下发月份分开。零分母为“—”。DIRECT 数据库业务数量为正、库存 Delta 为负、列表明细与 Excel DisplayQuantity 为负，ActualQuantity 合计始终用正数并按单位分组。

库存提交即时生效，补录日期决定报表归属，不回放过去的物理库存。业务报表为当前有效单据；inventory-ledger 为完整审计流水（含冲销）。对账命令检验仓库余额=完整有符号流水累计、在外余额=完整在外流水累计，并校验守恒及产出/实收明细。错误退出码1，不自动修复。
