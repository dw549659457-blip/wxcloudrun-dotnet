# 棚户记账 1.1.0：界面优化试上线版

AppID：`wx336b5ac8bed80159`；云环境：`prod-d7glkv54o7189eae7`；云托管服务：`dotnet-4jwm`。工程中的公开配置已填写，开发账号登录关闭，使用现有微信绑定和业务接口。

## 这版优化

- 统一绿色主题、白色卡片、大字和留白；登录入口更紧凑，微信核实及协助流程清晰。
- 首页按司机、装菜员、出库员显示岗位工作台，突出主要记账入口和本人待办，记录查询与身份设置分区。
- 表单区分“填写本次 / 核对记账”；数量输入用24px大字与大号加减按钮，单位移到输入框上方；筛选日期、任务状态、库存数量与单号的层次更清楚。
- 明确空列表、加载中、出错和待确认状态。结果不明时继续确认原提交，沿用既有幂等机制。
- “我的身份”显示版本1.1.0，选择岗位只列司机、装菜员和出库员。

## 导入与试上线

1. 解压工程包，在微信开发者工具导入里面的 **vegetable-miniprogram** 文件夹；这个目录同时有 `project.config.json` 和 `miniprogram`。无需构建npm。
2. 用有该小程序开发者权限的微信登录工具，点“编译”，再点“预览”。可先清除旧工程编译缓存，避免显示上一个下载版本。
3. 请司机、装菜员、出库员各用本人账号核对岗位首页；在专门的测试棚户、批次和客户中做一笔完整流程，核对日期、数量、单位、正式单号和后台库存。
4. 在至少一台安卓和一台iPhone上检查：数字键盘展开、末行与确认按钮可见；大字号与较长姓名能换行；手机号核实和重新进入正常；断网后草稿仍在，未知结果能继续确认原提交。
5. 开发者工具点“上传”，版本号填 **1.1.0**，描述填“优化岗位工作台、记账表单、大字布局及状态提示”。上传后，在小程序管理平台“版本管理”设为体验版，添加体验成员，扫码试用。
6. 体验验收完成后，在管理平台提交审核，审核通过后发布。服务环境关联、手机号接口资格、隐私保护指引、类目与备案等以实际平台要求为准。
